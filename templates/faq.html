FAQ

Why is a quality unavailable?

The app checks the formats exposed by the source instead of pretending that every quality exists.

Why can a link fail?

Third-party sites change frequently. The downloader uses the current yt-dlp engine and retries selected extraction paths, but no downloader can guarantee every public URL forever.

Why does the final size differ from the estimate?

Estimates can change during streaming or merging. The completed file size is measured from the final media file before it is offered for download.

Where is the Windows file saved?

The Windows wrapper enables native downloads and uses the user's normal download location. The web interface also exposes an Open in folder action where the native wrapper supports it.
